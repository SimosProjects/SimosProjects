# Christopher Simonson

Senior full stack engineer with 9+ years of experience. My strongest side is the back end in C# and .NET, and I
build the front end in React Native and TypeScript.

I am building [Kyntra](https://kyntra.fit), an offline-first gym workout log for iOS and Android, under
[Meridion Systems](https://meridion-systems.com). I am its sole engineer: the mobile app, the API, the database, the
cloud setup and CI/CD.

## What I work with

- **Back end:** C#, .NET 10, ASP.NET Core, EF Core, PostgreSQL with PostGIS, xUnit with Testcontainers
- **Front end:** React Native, Expo, TypeScript, SQLite with Drizzle ORM, Jest and React Native Testing Library
- **Cloud and delivery:** Azure, GitHub Actions, EAS Build, Sentry
- **Practices:** offline-first sync, API design with OpenAPI, security reviews, architecture decision records,
  tests written with each feature
